# Design system: "Moomu Ledger"

หน้าเว็บหารบิลอ่านง่ายเหมือนสมุดบัญชี แต่หน้าตาน่ารักขี้เล่นตามแมว Moomu: สีทั้งหมดดึงจากสติกเกอร์ รูปทรงกลมมนแบบสติกเกอร์ และตัวเลขยังเด่นเสมอ
โทเคนทั้งหมดอยู่ที่ `:root` ใน [web/src/styles.css](../web/src/styles.css)

## หลักการ

1. **ตัวเลขคือพระเอก** ยอดเงินใช้ `<Money>` (ตัวเลข tabular) ให้ทศนิยมตรงกันทุกแถว ยอดหลักของหน้าใช้ `.hero-figure` (ฟอนต์ Mali)
2. **สีจากแมว Moomu** พื้นสีนม (`--paper`) ตัวอักษรสีลายเข้ม (`--ink`) ปุ่มหลักสีขนน้ำตาล (`--brand`) ไฮไลต์สีตาน้ำผึ้ง (`--honey`) และสีหูชมพู (`--pink`) ส่วนสีสถานะ:
   - `--due` ส้มอิฐอมชมพู = ยอดค้าง / ต้องจ่าย (ไม่ใช่ข้อผิดพลาด)
   - `--paid` เขียวธนบัตร = ชำระแล้ว (ไอคอนรอยเท้าแมว)
   - `--danger` แดง = ผิดพลาด หรือการกระทำที่ย้อนกลับไม่ได้
3. **สมาชิกจำได้จากสี** `memberColor(id)` ให้สีประจำตัวที่คงที่ ใช้ซ้ำกับรูปโปรไฟล์ (`Avatar ring`) ปุ่มกำหนดเจ้าของรายการ และแถบยอดต่อคน
4. **กล่องเท่าที่จำเป็น** ใช้ `.card` เฉพาะฟอร์มหรือขั้นตอนที่ต้องแยกเป็นหน่วย ข้อมูลอ่านอย่างเดียวใช้เส้นคั่น (`.ledger`, `.share-list`, `.ledger-hero`)
5. **การเคลื่อนไหวต้องบอกการเปลี่ยนสถานะ** ไม่ใช้เพื่อตกแต่ง

## Breakpoints

- `≤ 720px` เมนูย้ายไปแถบล่าง (นิ้วโป้งเอื้อมถึง) ปุ่ม "สร้างบิล" เป็นปุ่มหลักสีหมึก
- `≤ 640px` ใบเสร็จกับรายการที่อ่านได้เรียงซ้อนแทนวางคู่กัน
- `≤ 600px` modal กลายเป็น bottom sheet · ช่องกรอกใช้ 16px กัน iOS ซูม
- `≤ 400px` ซ่อนข้อความรองบนปุ่มเครื่องมือ

## คอมโพเนนต์ ([ui.tsx](../web/src/components/ui.tsx))

| คอมโพเนนต์ | ใช้เมื่อ |
|---|---|
| `Money` | แสดงยอดเงินทุกจุด `tone="due"` / `"paid"` เมื่อยอดนั้นมีสถานะ |
| `PaidTrack` | ความคืบหน้าการชำระของบิล: 1 ช่องต่อผู้ที่ต้องจ่าย |
| `Meter` | สัดส่วนต่อเนื่อง (ชำระแล้ว/ทั้งหมด, ความคืบหน้าการอ่านใบเสร็จ) ความกว้างเลื่อนเมื่อค่าเปลี่ยน |
| `Badge` | สถานะเป็นข้อความ + เครื่องหมาย (ทึบ = ชำระแล้ว, กรอบ = รอชำระ) เพื่อไม่พึ่งสีอย่างเดียว |
| `Avatar ring` / `AvatarStack` | ตัวตนสมาชิก / เจ้าของรายการ |
| `SkeletonRows` | ระหว่างโหลดรายการ แทน spinner เพื่อกันหน้ากระโดด |
| `useFreshKeys` | ไฮไลต์แถวที่สถานะเพิ่งเปลี่ยนจากเหตุการณ์สด (ไม่ไฮไลต์ตอนโหลดครั้งแรก) |

## การเคลื่อนไหวที่มีความหมาย

- เปลี่ยนขั้นตอนสร้างบิล: เลื่อนเข้าจากขวาเมื่อไปต่อ จากซ้ายเมื่อย้อนกลับ
- อ่านใบเสร็จ: เส้นสแกนวิ่งบนรูป + แถบความคืบหน้า + โครงรายการรอผล
- มีคนชำระ (เรียลไทม์): แถวสมาชิกกะพริบเขียวจาง สถานะ "ชำระแล้ว" ประทับเข้ามา ยอดถูกขีดฆ่า แถบ `PaidTrack` เติม
- แมว Moomu โผล่ข้างหัวข้อหน้า และส่ายหัวเป็นระยะ
- ทั้งหมดปิดเมื่อผู้ใช้ตั้ง `prefers-reduced-motion`

## ข้อควรระวัง

- ห้ามใส่ animation ที่มี `transform` บน `.main` หรือคอนเทนเนอร์ที่มี modal อยู่ข้างใน เพราะจะทำให้ `position: fixed` ของ modal ถูกจำกัดกรอบ
- ขนาดตัวอักษรรายชื่อในสรุปรายร้าน (`.line-member`) ใหญ่กว่าปกติ 50% ตามที่ผู้ใช้ขอ อย่าลดลง
